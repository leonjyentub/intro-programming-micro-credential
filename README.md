# 基礎程式設計微學分課程

本專案是國立臺北商業大學資訊管理系為四技與二技新生準備的「程式設計學習地圖」。教材以三天微學分課程為起點，協助尚未接觸程式，或只有少量經驗的學生，看懂資訊管理領域的修課路徑，理解程式設計在系統開發中的位置，並完成一次可持續練習的開發循環。課程不以短時間背完語法為目標，而是培養拆解問題、寫出步驟、執行驗證、閱讀錯誤及留下修改紀錄的能力。

資訊管理連結人、流程、資料、系統與商業需求。教材以校園活動報名服務為例，說明一項資訊服務如何從使用者需求出發，逐步連到前端介面、後端規則、資料庫、行動應用、伺服器維運與資訊安全。學生也能從四技、技優領航、二技日間及進修學制的課程安排中，認識程式、資料結構、網路、雲端、資安與專題之間的關係，並探索網站、App、資料分析、AI、系統分析或維運等發展方向。

教材介紹 Java、Python 等語言的共同核心，以及 Django、Flask、Spring Boot 等框架與套件生態。學習重點包括輸入輸出、條件、迴圈、函式、資料結構、檔案與例外處理，並進一步理解資料庫、SQL、API、測試與跨平台應用。作品練習由成績計算器、猜數字和文字工具開始，逐步發展成待辦清單、資料管理程式，以及結合資料庫與網站或 App 的小型系統，讓每次練習都成為可重用的作品集素材。

## 從課程能力到專案作品

![從程式設計基礎到專案實作的學習心智圖](assets/project-learning-mindmap.svg)

這張學習心智圖把專案實作放在中央：左側的程式設計基礎與資料結構，支援規則撰寫及資料處理；右側的網站／行動應用、商業邏輯與 UI／UX，則把功能帶到使用者面前，讓流程正確、介面易懂。專題不是把課名拼在一起，而是把這些能力放進同一個真實問題中協調。學生不必一開始全部精通，先從指定語言與基本解題練穩，再逐步補上能讓作品可靠運作的元件。

實作單元涵蓋 Windows、macOS 與 Linux 的檔案路徑及終端機操作，並以 VS Code 建立 Java 或 Python 開發環境。Git 與 GitHub 單元帶領學生理解 repository、commit、branch、merge、clone、push、`.gitignore` 與衝突處理，養成先看 `status`、再看 `diff`、測試後才提交的習慣。DOMjudge 則以測資與判定結果建立「正確必須可驗證」的觀念。

AI 協同學習部分將聊天、程式協作與代理操作分成不同授權層級。學生可請 AI 解釋觀念、提供提示、設計測資或檢查可讀性，但仍須親自執行、理解、測試與說明每項修改。使用 AI agent 時，任務應明確寫出目標、範圍、限制與驗收方式，並遵守不提供個資與帳密、採最小權限、保留 Git 版本及符合學術誠信等原則。
